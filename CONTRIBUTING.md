# Contributing to Kami

Thanks for helping build Kami.

## Ground rules

- Keep the editor usable for solo developers and creators.
- Prefer general, reusable app-store layouts over niche one-off templates.
- Keep `screenshot-studio.json` portable and reviewable in Git.
- Never commit secrets or generated export bundles.
- Add or update documentation when changing the project file format or export behavior.

## Before opening a pull request

1. Run the relevant tests and checks.
2. Confirm generated files are not included unintentionally.
3. Review changes to `screenshot-studio.json` for backward compatibility.
4. Include screenshots or a short recording when a change affects the editor UI.
